# AI浪潮 · 每日新闻视频模板

视频号「AI浪潮」每天一期的 AI 新闻竖屏视频。分工：Grok Bot 搜集新闻，Claude 做视频，成片统一 **1.4 倍速**交付。

## 每天的时间

| 时间（北京） | 谁 | 做什么 |
|---|---|---|
| 05:30 前 | Grok Bot | 把当天情报写进交付表格，最后一行 B 列写「完成」 |
| 05:47 | Claude（定时任务） | 读表 → 出视频 → 1.4 倍速 → 交付 → 删掉读过的行 |

观众大多在早上通勤路上看，成片要在 07:00 前交到 Tony 手上。

交付表格：[AI浪潮 · 新闻情报交付](https://docs.google.com/spreadsheets/d/1HofIP71ahTkJpePOLxbIenHYunL5Jv0L9ZnExwXguJE/edit)（「情报」页是数据，「说明」页是填写规则）。
Grok Bot 的提示词在 `grok_prompt.md`。

## 文件

- `episode.html`：视频模板，1080×1920，30fps。`render(t)` 按时间画出一帧。
- `cover34.html`：视频号 3:4 封面。
- `render.py`：`python3 -I render.py stills 4,17.5 "" episode.html` 出检查图；`python3 -I render.py video out.mp4 "" episode.html` 出整条画面（无声）。
- `examples/ep001/`：第 001 期（2026-10-22）的成品，新做一期时照着改。

## 视觉规范（每期不变）

- 配色：钴蓝 `#0038FF` 底、荧光黄 `#F2FF00` 强调、墨黑 `#0A0A0A`、白。结尾页换成黄底。
- 字体：Noto Sans CJK SC，标题 900 粗。
- 结构：封面（AI / 浪潮 撞入 + 铬色浪线）→ 每条新闻一屏 → 结尾（评论引导 + 关注）。
- 新闻屏固定版式：左上空心编号 `01`、来源标签（如 `OpenAI · Codex`）、白色信息卡（900×470，黑粗边、硬阴影、-2° 倾斜）、右上圆形黄贴纸（≤3 字一行，两行）、下方两行大标题（关键词用 `<span class="k">` 变黄）。
- 信息卡里画一个跟这条新闻有关的小信息图（进度条、数字倒数、日历印章、截图示意等），跟着口播在关键句出现变化，不用真实品牌 Logo。
- 转场：每屏之间一道黄色波浪扫过；底部滚动栏目条；顶栏进度格数 = 新闻条数。
- 安全区：内容放在 y 300~1360；字幕在 y 1402~1522；1600 以下只放滚动条（会被平台按钮挡住）。

## 每期流程

1. **读表**：读「情报」页全部行。没有「完成」行说明 Grok Bot 还没写完，20 分钟后再看，最多等两次，再没有就告诉用户。
2. **选题**：挑 3~5 条能公开发的，按序号排，「钩子」行建议的那条放第一条。不收：内部业务（Nora Lane、闲鱼秘书等）、核实状态是「有争议」或「仅单一来源」且没有官方链接的条目。
3. **口播稿**：
   - 开头：「AI浪潮，X月X日。」+ 一句钩子。
   - 每条 1~2 句，一句一个配音片段；第二条起用「第二条」「第三条」「最后提醒」开头。
   - 结尾固定：「你最想让AI替你干哪件活？评论区告诉我。关注AI浪潮，每天一分钟，不错过一个浪头。」（问题可以按当天内容换）
   - 配音文字里数字写成汉字读法（「四万」「二百零四」），字幕里用阿拉伯数字。
4. **改模板**：把 `episode.html` 复制到工作目录，改：
   - `window.EP`：期号（`no`，第 001 期是 2026-10-22，之后每天 +1，三位数）、`md`（10.22）、`ymd`（2026.10.22）、`full`（2026.10.22 THU）。
   - 每个新闻屏 `n1..nN` 的编号、标签、信息卡、贴纸、标题，以及 `S.n1..S.nN` 里的动画时间点。条数变了就增删对应的 scene 和顶栏进度格。
5. **配音**：用剪辑工具的 `tts`，固定用 Tony 选定的声音：`model="microsoft/mai-voice-2.1"`、`voice="zh-CN-Mei:MAI-Voice-2.1"`、`gap=0.35`（显式传，不靠服务器默认值），拿到每句时长。看 `verify.flagged`，有念错的改写法重配。
6. **对时间轴**：每屏比它的第一句早 0.3 秒开始；同屏句子间隔 0.35 秒；跨屏间隔 0.7 秒；每屏在最后一句结束后 0.45 秒切走。把结果写进 `TL.scenes`（`[id, 开始, 结束, 第二句开始]`）、`TL.subs`（`[开始秒, [字幕分段…]]`，每段 ≤16 字）、`TL.durs`（每句时长）。动画的关键变化要对上口播里说到它的那一刻。
7. **检查**：每屏出一张检查图看一遍，文字不能出界、不能被贴纸挡住、不能和字幕重叠。
8. **出画面**：`render.py video` 出无声画面。
9. **传进剪辑工具**：把 mp4 用孤立提交强推到本仓库的 `tmp-media` 分支（文件名 `ai-wave-YYYYMMDD.mp4`，每天覆盖），再用 `import_video` 导入 `https://raw.githubusercontent.com/Tony11081/douyin-editor/tmp-media/<文件名>`。
10. **混音 + 1.4 倍速**：`mux`，`voiceover.at` 按变速前的时间轴写，`bgm: {name: "mixkit_driving_ambition.mp3", volume: 0.12, fade_out: 2}`，`speed: 1.4`。用 `get_frames` 抽 4 帧确认。
11. **封面**：改 `cover34.html` 的大字钩子和底部两个小标签，截 1080×1440 的图。
12. **交付给用户**：成片下载链接、封面图、口播稿、视频号发布文案（标题 + 正文 + 话题标签）。
13. **删行**：交付完成后，删掉「情报」页里这次读过的行（保留表头）。
