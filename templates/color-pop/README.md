# 48 · 多彩动感（Etsy-Tony 日更）

1080×1920 / 30fps，`render(t)` 逐帧画，渲染同 ai-wave：`python3 -I render.py stills 2.7,8.4 "" episode.html` 出检查图，`python3 -I render.py video out.mp4 "" episode.html` 出无声画面。

- 配色：墨紫黑 #16122B、奶油 #FFF6E9、番茄红 #FF4B2B、电光紫 #5B2EFF、向日葵黄 #FFC233、薄荷绿 #10C99A、桃粉 #FF4F9A、天蓝 #2EB8FF。每屏换一个底色，背景有流动光斑和颗粒。
- 结构：封面（大字砸入 + 爆炸贴 + 小贴纸连拍）→ 每条一屏（编号+速度线、标签、信息卡、爆炸贴、两行大标题）→ 结尾（投票条 + 评论引导 + 关注）。
- 动效层 `window.FX`：贴纸拍上（带镜头震动）、关键词逐字弹跳 + 手绘圈自动描出、闪光星、速度线、进场镜头推拉。每屏贴纸写成 `[文字, x, y, 角度, 底色, 字色, 拍上时间]`。
- 转场：五色斜条带扫过；底部两条交叉滚动彩带（会被平台按钮挡，只做装饰）。
- 安全区：内容 y 300~1360，字幕 y 1402~1522。
- 改内容：`window.EP`（brand、md 日期）、各屏文字、`TL.scenes` / `TL.subs` 时间轴、`FX` 贴纸。配音按日更规矩 1.3 倍，只加速配音。
