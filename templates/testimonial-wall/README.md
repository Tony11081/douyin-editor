# 口碑墙 · 视频动效模板（44 / 45 号）

把客户评价做成一段 8 秒左右的竖屏动效（1080×1920，30fps，无声），可以单独发，也可以剪进宣传片当一个镜头。视觉和 openaigrowth 首页一致：锌黑底、荧光青柠 `#C8FF00`、标签用等宽字。

| 号 | 风格 | spec.style | 时长 | 镜头 |
|---|---|---|---|---|
| 44 | 倾斜滚墙 | `wall` | 8 秒 | 整面卡片墙倾斜、四列错向滚动、镜头拉远、标题逐字升起 → 墙虚化，主角卡从墙里弹出 → 结尾网址按钮 |
| 45 | 星环隧道 | `vortex` | 8.5 秒 | 光速穿过贴满评价卡的旋转隧道，标题冲向镜头 → 闪光，小卡从远处飞来拼成一颗大星星，冲击波 + 一句话 → 星星炸开，主角卡翻转飞入，逐字打出原话、边框光绕一圈 → 结尾网址按钮 |

## 怎么出片

```bash
# 先出几张检查图（当前目录生成 still_<秒>.jpg）
python3 -I render.py stills spec.json 1.5,4.2,6.8
# 整条
python3 -I render.py video spec.json out.mp4
```

本机 Chrome 不是 Playwright 自带的那个时，设环境变量 `CHROME_PATH=/usr/bin/google-chrome`。成片码率上限 10M（H.264 High@4.1），和剪辑工具一致。配音和音乐交给剪辑工具（`mux`，或 `render` 的 voiceover / bgm），按这个视频所属方向的固定配音和模板来。

## spec.json

照 `example.json` 改。

| 字段 | 说明 |
|---|---|
| `style` | `wall` 或 `vortex` |
| `duration` | 秒，可省（默认 8 / 8.5）；改了以后所有时间点按比例伸缩 |
| `eyebrow` / `title` | 小标题；大标题按词拆成数组，逐个升起，一共 6~8 个字最好 |
| `shapeCaption` | 只有 `vortex` 用：星星下面那句话，逗号后半句变绿 |
| `cta` / `sub` | 结尾按钮文字（网址）和下面一行小字 |
| `watermark` | 可省。右上角提示（预览版写「效果预览 · 卡片内容为示例」，正式版删掉） |
| `cards` | 墙上的卡，8~16 张，会循环铺满 |
| `hero` | 最后放大的主角卡，可省（省了用第一张） |

卡片 `kind`：

- `quote` 原话：`text`（用 `[[关键词]]` 标绿）、`who`、`meta`、`result`（可省，底部绿点一行）
- `chat` 聊天截图：`bar`（群名）、`msgs`：`[[0, "对方说的"], [1, "我们回的"]]`，对方头像自动打码
- `review` Etsy 好评：`stars`（1~5）、`text`、`who`、`meta`
- `number` 数字：`value`、`text`

每张卡都有 `group`（左上角分类，如「素材包客户」「学员」「ETSY 买家」）和 `sample`。

## 内容规矩

- **只放真实评价。** `sample: true` 的卡左上角会显示「示例」，只用于给 Tony 看效果；正式发布的成片里所有卡都必须是真实内容，`sample` 写 `false`，并删掉 `watermark`。
- 客户名字打码或只留称呼（「黄总」「学员 D」），群聊对方头像模板会自动模糊；订单号、买家全名、店铺数据不上画面。
- 原话尽量照抄，可以删减不改意思；数字卡要能拿截图核对。
- 公开客户的聊天前最好先问过本人。

## 安全区

主要内容在 y 300~1360；结尾按钮在 y 1300 左右；1600 以下会被平台按钮挡住，不放东西。
